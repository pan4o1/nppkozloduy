# Пазарни консултации — АЕЦ Козлодуй

Публичен, независим dashboard за търсене и преглед на обявените пазарни консултации на АЕЦ „Козлодуй“. Данните се извличат от [официалния регистър](https://www.kznpp.org/bg/pazarni-konsultatsii).

## Функционалност

- автоматично зареждане на последните налични данни при всяко отваряне;
- обновяване на регистъра на всеки 6 часа чрез GitHub Actions;
- търсене по заглавие, описание и референтен номер;
- филтри по статус, категория и дата на публикуване;
- статистика за активни, приключващи скоро и публикувани през годината обяви;
- откриване на публикувани индикативни предложения и визуализиране на участниците, когато имената им присъстват в официалните файлове;
- филтър за консултации с публикувани предложения и директни връзки към файловете;
- адаптивен интерфейс за компютър, таблет и телефон;
- директна връзка към всяка официална обява.

## Публикуване с GitHub Pages

1. Качете проекта в GitHub repository с основен branch `main`.
2. В **Settings → Pages → Build and deployment → Source** изберете **GitHub Actions**.
3. Workflow-ът `Deploy dashboard to GitHub Pages` ще публикува сайта автоматично.

За автоматичните актуализации трябва GitHub Actions да има право да записва в repository-то: **Settings → Actions → General → Workflow permissions → Read and write permissions**. Workflow-ът може да се стартира и ръчно от таба **Actions**.

## Локален преглед

```bash
python3 -m http.server 8080
```

След това отворете `http://localhost:8080`.

## Обновяване на данните

```bash
python3 scripts/scrape.py
```

Скриптът използва само стандартната библиотека на Python. При локална Python инсталация без коректно конфигуриран сертификатен пакет може временно да се използва `--insecure`; CI workflow-ът винаги проверява TLS сертификатите.

## Бележка

Dashboard-ът не е официален сайт на АЕЦ „Козлодуй“. При разминаване меродавна е информацията и документацията в официалния регистър.

Броят предложения се определя само от файловете, публикувани към отделните консултации. Възможно е да има подадени, но непубликувани предложения. Участник се показва по име само когато то може да бъде разпознато надеждно от името на официалния файл.
